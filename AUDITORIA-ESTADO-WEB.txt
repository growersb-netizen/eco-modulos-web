5. GAPS CRÍTICOS
================================================================================

BLOQUEANTES — NO SE PUEDE IR A PRODUCCIÓN SIN ESTOS
------------------------------------------------------

[1] middleware.ts NO EXISTE — CRÍTICO DE SEGURIDAD
    El archivo middleware.ts que protege /admin/* no fue creado.
    Solo existe dentro de node_modules/next-auth, no en la raíz del proyecto.
    Consecuencia: cualquier persona que conozca la URL puede entrar directamente
    a /admin/dashboard, /admin/leads, /admin/config sin autenticarse.
    El login existe y funciona, pero no hay nada que lo fuerce.
    Solución: crear middleware.ts en la raíz del proyecto (5 minutos de trabajo).

[2] Cloudflare R2 NO CONFIGURADO
    Variables en .env.local:
      R2_ACCOUNT_ID=tu_account_id     (placeholder)
      R2_ACCESS_KEY_ID=tu_access_key  (placeholder)
      R2_SECRET_ACCESS_KEY=tu_secret_key (placeholder)
    Consecuencia: el upload de imágenes desde el admin devuelve error 503.
    El admin tiene que pegar URLs de imágenes externas manualmente.
    Solución: crear API key en Cloudflare R2 y cargar las credenciales reales.

[3] NEXTAUTH_URL apunta a localhost
    Variable actual: NEXTAUTH_URL=http://localhost:3000
    Consecuencia: en Vercel, NextAuth va a usar localhost para los callbacks,
    el login va a redirigir incorrectamente y el sistema de sesiones va a fallar.
    Solución: cambiar a https://ecomodulosypiscinas.com.ar en las env vars de Vercel.

[4] No hay deploy en producción
    El sitio no existe en ninguna URL pública.
    No hay proyecto en Vercel, no hay dominio configurado.
    Solución: crear proyecto en Vercel, cargar todas las env vars, conectar dominio.

[5] Sin imágenes en todo el sitio
    El sitio en producción va a tener tarjetas de productos sin foto,
    galería de obras vacía, blog sin imágenes destacadas,
    y el tag OG va a mostrar imagen rota en redes sociales.
    Solución: configurar R2 primero, luego cargar imágenes desde el admin.


IMPORTANTES — AFECTAN FUNCIONALIDAD PERO NO BLOQUEAN EL DEPLOY
----------------------------------------------------------------

[6] og-image.jpg no existe
    Todos los metadatos OG referencian /og-image.jpg.
    Google, WhatsApp y Facebook mostrarán preview sin imagen al compartir
    cualquier página del sitio.
    Solución: crear imagen 1200×630 px y colocarla en /public/og-image.jpg.

[7] Simulador no captura leads
    Cuando alguien usa el simulador y ve su cuota, no hay formulario de captura.
    El link va directo a WhatsApp. Si el usuario no manda el mensaje,
    el lead se pierde. No queda ningún registro de que alguien simuló.
    Solución: agregar un mini-form después del resultado del simulador.

[8] Multiagente no está conectado al sitio
    La API proxy /api/chat existe y está bien implementada, pero ningún componente
    del frontend la utiliza. El multiagente deployado en Fly.io está desconectado
    del sitio web. No hay chat, no hay asistente IA visible para el usuario.
    Solución: crear un componente de chat widget que use /api/chat.

[9] Números de WhatsApp duplicados
    Stefanía, Hernán y Daniel tienen el mismo número en .env.local.
    El router de vendedores funciona en código pero no tiene efecto real.
    Solución: actualizar las variables WA_STEFANIA, WA_HERNAN, WA_DANIEL
    en Vercel con los números reales de cada vendedor.

[10] Editor de blog es HTML raw
     El admin escribe HTML crudo en el editor de artículos.
     No hay WYSIWYG ni Markdown. Funciona pero es incómodo para
     alguien no técnico.
     Solución: integrar un editor como TipTap o SimpleMDE (trabajo adicional).
